# Zeni Consulting

Strategic IT consulting for growing businesses. We design systems that scale.

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:4321`

## Build

```bash
npm run build
```

Static output in `dist/`

## Structure

- **Home** — Hero, About, Services, Why Zeni, Process, Tools, CTA
- **About** — Philosophy, How we work, Engagement model, Leadership
- **Services** — IT Strategy, System Development, Process Automation, Technology Audit
- **Case Studies** — Sample projects with Problem → Solution → Outcome
- **Contact** — Form, WhatsApp, Email, Calendly
- **Blog** — Placeholder for thought leadership (future)

## Tech

- [Astro](https://astro.build) — Static site generator
- Design: Navy (#001845), Accent (#0466C8), Plus Jakarta Sans + Inter
